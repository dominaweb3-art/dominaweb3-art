### [C Market — Solana Mobile prototype](https://github.com/dominaweb3-art/cmarket-clock-in)

A mobile-first experimental crypto-basket experience for the Solana Mobile ecosystem. The documented **Expo / React Native** prototype covers mobile-wallet connection, Devnet USDC balance checks, a test purchase/payment flow, transaction confirmation, and activity history.

**Product and delivery focus:** turning a product concept into an MVP, defining user flows, reviewing technical constraints, documenting scope and limitations, and iterating on the mobile experience.

> **Prototype status:** Devnet functionality demonstrates payment routing and confirmation; production-ready allocation of basket assets has not been established. This is not a live financial product.
